# Safe-Gate
A sensor-based autonomous parking barrier designed with a focus on vehicle safety and anti tailgating.
# Overview:
It detects an approaching vehicle, opens up the parking, monitors the passage of the vehicle, closes the barrier when the passage is clear.
# Features:
Vehicle approach detection 
Servo controlled barrier
passage detection
anti tailgating 

# Hardware:
Arduino Uno - main controller
HC SR04 - ultrasonic sensor
IR sensor
breadboard and jumper wires
LEDs - red, yellow, green
Resistor - 220 ohm, 1k ohm, 2k ohm
