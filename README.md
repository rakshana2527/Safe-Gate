# Safe Gate

A sensor-based automatic parking barrier made to improve vehicle entry and exit safety.

## Overview

Safe Gate detects an approaching vehicle using an ultrasonic sensor and opens the barrier using a servo motor. An IR sensor tracks whether the vehicle has passed through, and the OLED display shows live distance, IR status, and gate state.

## Features

- Vehicle approach detection
- Servo controlled barrier
- Vehicle passage detection
- OLED status display
- Buzzer alert
- ESP32-based control

## Hardware

- ESP32 development board
- HC-SR04 ultrasonic sensor
- IR sensor
- SG90 servo motor
- OLED display
- Buzzer
- Breadboard and jumper wires
- 220 Ω, 1 kΩ and 2.2 kΩ resistors
